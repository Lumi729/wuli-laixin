# 薄雾来信：冷白素材修复

导入文件：`theme/Blue-Clean.json`。主题名称保持现有冷白银蓝版本的名称。
导入前先导出旧主题备份；用新主题替换旧主题，不要把 CSS 追加到旧 CSS 后面。

## 保留的行为

从 `theme/rose-moon-phases.css` 构建，保留原版的消息布局、16:9 头像容器、计数排列、姓名、按钮位置、正文尺寸、滚动和响应式规则。没有改头像裁剪，也没有增加脚本。

## 素材适配

- 重新准备冷白、银灰、蓝色的透明花框、底饰、姓名缎带与姓名两侧花枝。
- 底饰的花叶、枝条、缎带之间应为真实透明空隙，不使用灰色或白色底板填充。
- 头像框只校正装饰绘制层的偏移，让下角贴合原来的头像底边；头像容器不动。
- 姓名缎带、底饰和按钮框按自然比例绘制。按钮框使用完整等比图片，避免展开操作时切片重复花饰。
- 顶栏与输入框保留九宫格边框，校正原尺寸切片并等比绘制角饰。
- 沿用仓库已有的冷色图标；不恢复偏黄高清图标。

素材通过内置图像编辑工具分离和修色，随后导出带 Alpha 的 WebP。导出只进行等比缩小、透明画布适配及左右镜像；没有将花饰压扁或拉长。重绘并不代表与参考稿逐像素相同。

核心编辑要求：保持勿忘我花饰、银灰叶片、蓝色缎带、白色信封的原构图；所有花心使用蓝色；禁止米黄、金黄、橄榄色和褐色；删除外缘残底及花枝内部封闭空隙的灰色衬底，空隙为 Alpha 0，不以白色替代。

## 验证范围

在 Chromium 样例 DOM 中比较 360、390、430、800 像素宽度：普通消息和长消息的头像、姓名、按钮、正文及输入框几何与玫瑰月相一致；没有横向溢出；“更多”按钮可展开。

`blue-clean-fixture.html` 是布局验证样例，不是手机酒馆实机。尚未验证用户手机和全部第三方插件组合。预览使用头像占位区域，不替换用户头像。

主题只引用所需的独立外链图片，可缓存复用；没有内嵌 Base64、动画或新增模糊效果。仓库中的历史素材不会因其存在而被该主题全部加载。

重建：在仓库根目录运行 `python tools/build-clean-theme.py`。
