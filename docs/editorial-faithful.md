# 夜航档案与橘子汽水 · 原图布局版

先在酒馆扩展管理中更新本仓库的「浮窗收纳」扩展，并刷新页面，再导入 theme/Night-Log-Faithful.json 或 theme/Orange-Soda-Faithful.json。扩展版本为 1.2.0。

本版重建了参考图的共享人物栏、纸张拼贴、窗景、便签和输入区。原有主题不变；新增布局适配仅在这两个主题启用，切换其他主题自动移除。头像、角色名、计数和思考内容读取实际消息，不写死在插画里。照片栏使用同一角色头像的三次等比裁切。

所有插画为独立外链 WebP；主题不嵌入 Base64。素材按原比例显示，长消息继续扩展内容区域，不拉长装饰图片。原生消息和按钮没有被替换成图片。

## 验证与限制

docs 中的 faithful 预览来自浏览器渲染的原生 DOM 模拟页面，而非用户酒馆的实机截图。1024、800、390 三种宽度均验证图片加载、无横向溢出、长消息滚动、姓名同步、更多按钮展开、切换主题移除布局。结果见 faithful-validation.json。

参考图中虚构的导航功能改为酒馆实际功能；头像、文案、字体换行随真实内容而变。因此不是将整张概念图当作可交互页面，也不能承诺所有设备逐像素相同。其他扩展自行插入的浮窗不受此主题控制。
