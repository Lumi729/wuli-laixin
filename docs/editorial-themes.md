# 夜航档案 / 橘子汽水

两套新设计，未替换现有主题。分别导入 `theme/Night-Log.json` 或 `theme/Orange-Soda.json`。替换整个自定义 CSS，不要把它们追加到其他主题后。

## 布局

- 夜航档案：左侧头像与计数、右侧姓名及正文，段落侧边操作栏，独立思考纸页、海图底饰、蓝色用户回信。
- 橘子汽水：圆头像与标题组成名片，左侧票券操作栏、绿色思考便签、奶油色消息纸与橘色用户回信、猫咪书堆底饰。
- 顶栏原生九入口、头像、三项原生计数、姓名、消息操作、思考区、正文、底饰、消息间距与分隔、用户消息、滑动切换、输入五入口均已处理；设置抽屉沿用原生结构并统一配色。

这是一版可导入实现，不是把概念图当背景。概念图里的静态角色合集和演示文字不注入聊天。真实姓名、头像、正文、计数和功能由酒馆提供。为保持原生数据与交互，档案头像随各条消息显示，思考区留在其所属消息内；并非跨消息固定侧栏。不会硬编码概念图的人名、数字或对话。

## 素材及性能

插画用内置图像生成工具重新制作透明独立素材：夜航海港条、航海图底饰、橘猫书本底饰、汽水瓶贴纸。提示要求：参照已批准设计，细线哑光水彩，独立透明轮廓，不含文字及人物，不画整张界面；只等比缩小导出 WebP。小型界面图标为独立 SVG。

主题只引用外链，无 Base64、无 JavaScript、无模糊或动画；装饰使用 contain 或单轴 auto，始终保留宽高比。人物图像使用 object-fit:cover 适应新头像形状（裁剪，不压缩拉伸）；可继续更换角色头像。SVG 图标通过外链遮罩着色。

同一主题首次加载插画合计不足 0.4 MB，随后复用浏览器缓存。网络需可访问 raw.githubusercontent.com。不能保证用户全部插件组合无冲突。

## 验证

`docs/*-fixture.html` 是依据 SillyTavern 原生消息 DOM 制作的样例页面，使用导出的同份 CSS，不是酒馆实机截图。演示头像只在 fixture 中，不包含在主题里。

Chromium 134，360 / 390 / 430 / 800 CSS px，检查：短消息和 30 段长消息无横向溢出、头像尺寸、示例图片加载、更多操作展开、思考收合。细节见 `editorial-validation.json`。已修正原生 mes_block 和 mes_buttons 的 overflow 会裁断侧边操作栏的问题，未强制显示原生隐藏的功能按钮。

`night-log-390.webp` / `orange-soda-390.webp` 为手机宽度样例截图，800 版为宽屏截图。未在用户手机或完整插件环境中验证。
