# 蜜瓜花笺

按用户认可的浅蜜瓜绿预览制作：左侧白铃兰、右侧轻缎带，单层姓名纸签、稀疏按钮框和左侧信笺底饰。沿用玫瑰月相的酒馆选择器及响应式布局，头像保持 16:9，不改头像裁剪行为。

素材为分别重绘的透明图像；没有裁切预览纸面充当素材。底饰按原有左、中、右三个相邻区段导出，所有花饰等比缩放。栏框采用角花等比的九切片，只有直线段随栏宽和高度延展。每枚图标为独立方形 WebP。背景是 CSS 纯色，图片只走 GitHub 外链，无内嵌 Base64、动画、脚本或新模糊效果。

透明度检查使用浅底与深底，花环中心、面具眼孔、缎带间隙透出底色。图标白色纸面与花瓣已去除偏黄版本。外链素材总计约 1.25 MB，首次下载后由浏览器缓存；不能据此保证所有设备与插件都不卡顿。

## 导入

下载 `theme/Honeydew-Letter.json`，在酒馆主题设置中导入并选择「蜜瓜花笺」。原「薄雾来信」文件保持不变。不要把本版 CSS 追加到旧主题上。

## 验证

Chromium 样例 DOM 在 360、390、430、800px 下加载无缺失资源、无横向溢出；头像、计数、姓名、按钮与输入区域的测量尺寸和现版蓝色主题一致；按钮展开与长正文检查通过。预览为实际样例 HTML/CSS 渲染，不是手机实机截图。尚未验证用户手机与全部插件组合。

## 绘制记录

使用内置图像编辑，以用户批准的「蜜瓜花笺」预览为风格参考，独立绘制头像框、底饰、姓名纸签、按钮框、栏框、图标图集和正文小花枝。提示要求：保留批准的细线插画风格、浅暖蜜瓜绿与干净白花、透明缝隙、无灰底、自然比例。栏框二次修正将花饰限制在四角；图标二次修正白纸和白花的暖黄偏色。导出仅做等比缩小、透明画布摆放及相邻模块切片。
