# 原版尺寸冷白银蓝修正

基于当前主题，只替换重画的边框和修色头像框，保留当前消息、计数、姓名、正文与按钮布局。

边框的逻辑画布采用玫瑰月相原文件 941×95；导出为 2823×285 三倍图。四角为 135×66（原切片45×22的三倍），角部严格等比缩放。中间直线重复铺设，运行时使用 border-image-repeat:repeat，禁止把花饰作为可伸缩边段。顶栏、输入框沿用原版位置。

头像框保留1606×979尺寸与原有轮廓，仅由图像工具修正为冷白银蓝及平滑边缘。不再使用偏黄的高清旧图。

验证：JSON/CSS一致；头像中心透明；分别合成顶栏和输入框两种高度，确认角饰比例一致。合成检查不是手机酒馆实机验证。
