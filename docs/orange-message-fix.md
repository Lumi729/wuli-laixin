# 橘子汽水普通消息修复

直接导入 Orange-Message-Fix.json，无需更新扩展。

取消消息正文两列网格、mes_block 的 display:contents、标题零高度、消息按钮绝对定位、固定消息最小高度。正文改为90%聊天区宽度；消息按内容增长；思考区仅在存在真实内容时显示。删除带空头像位和空便签的整张消息背景，保留头栏、导航、输入框和等比纸张外链纹理。因此消息区装饰与原概念图不同，此版解决普通消息错位，不声称像素级复刻。

测试：官方 HTML 消息模板和 CSS，390/1024 宽度，普通纯文本消息；输入、发送点击命中、设置按钮、长消息滚动到底、正文宽度至少聊天区88%、无横向溢出通过。测试未调用API，未在用户设备实测。
