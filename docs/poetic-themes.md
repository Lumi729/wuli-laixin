# 四款独立布局 · 试用版

在酒馆「用户设置 → 界面主题 → 导入」中，分别导入 ZIP 内的 JSON，再选择对应主题。

- 星潮夜航：星海横向大头像、深蓝正文区。
- 月兔涂鸦：蜡笔圆头像、兔子贴纸、白色手账纸。
- 雨声留白：雨窗照片头像、透明伞与风铃、浅蓝白正文区。
- 云端邮局：右侧邮票头像、云端信纸、航空信封折边。

这四款使用新的独立布局，不会覆盖薄雾来信或蜜瓜花笺。可随时切换回原主题。
头像来自当前角色/用户图片，示例人物不包含在主题内。为融入圆框、照片和邮票，头像使用等比裁切，不会压扁或拉伸。

素材由独立图集绘制并通过 GitHub raw 外链加载，JSON 不含图片 Base64；浏览器会缓存素材。首次加载需要能访问 raw.githubusercontent.com。

预览是使用酒馆结构样例在 Chromium 中实际渲染的截图，并非用户设备截图。已检查 360、390、800 像素宽度、长角色名、长消息、用户/角色消息衔接及更多按钮展开。不同酒馆版本或其他插件 CSS 仍可能影响最终结果。

生成的概念图仅用于设计参考，代码版以本次实际渲染截图为准。装饰使用独立透明 WebP，自然比例缩放；正文长度由真实内容决定。
