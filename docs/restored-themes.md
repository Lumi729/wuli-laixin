# 四款主题 · 预览还原版

在酒馆的用户设置 → 界面主题 → 导入中，选择压缩包里的 JSON。主题名称带「还原版」，请选中这一版；无需卸载原来的薄雾来信或蜜瓜花笺。

本版重新绘制并接入了星海旋涡、蜡笔撕纸、水滴雾面、折叠信纸等素材。素材是独立绘制的图层和小块纹理；没有把概念图裁成整页背景，也没有在 JSON 中嵌入 Base64 图片。图片由 GitHub raw 外链加载并由浏览器缓存。

角色头像和用户头像来自酒馆当前图片，预览用的示例人物不包含在主题文件中。头像以 cover 等比裁切融入各自的窗口，不会横向或纵向拉伸。装饰图像用自然比例缩放，长消息通过延展材质和移动底部装饰适配。

这次的 PNG/WebP 预览由相同 JSON 内的 CSS 在酒馆结构样例页面中实际渲染，不是用户手机截图。保留了酒馆实际的顶栏入口、编号、计时和消息操作按钮；这些控件的数量以酒馆及已安装插件为准。不同角色图片的裁切、字体和插件样式可能影响实际显示。

验证覆盖 360、390、800 像素宽度：角色头像加载、按钮展开、长名字、长文本与代码块、连续角色/用户消息、页面横向溢出以及正文与头部交叠。所有引用的位图也均通过解码检查。

生成 CSS/JSON：python tools/build-poetic-restored.py
QA：node tools/verify-restored.cjs（可通过 CHROMIUM_PATH 指定 Chromium，QA_FONT 指定中文字体）
